Cómo se usa LabRed

Montar la red

  1. Elige un dispositivo en la barra izquierda y haz clic en el lienzo para colocarlo.
  2. Con la herramienta Cable, haz clic en un dispositivo y después en otro. Se usa el primer puerto libre de cada uno.
  3. Selecciona un equipo para configurarlo en el panel derecho: IP, máscara, puerta de enlace, DNS, servicios o rutas.
  4. Haz doble clic en un PC, servidor o router para abrir su consola. Los PC también tienen navegador.

Los equipos con un círculo naranja ! tienen algún problema de configuración: selecciónalos para leerlo.

Comandos de la consola

ipconfigMuestra la configuración de red. ipconfig /all, /renew (pedir IP por DHCP), /release.
ping <destino>Comprueba si un equipo responde (ICMP). Acepta IP o nombre. -n 2 cambia el número de envíos.
tracert <destino>Muestra los routers por los que pasa el paquete (usa el TTL).
arp -a / arp -dVer o vaciar la tabla ARP (IP ↔ MAC).
nslookup <nombre>Pregunta al servidor DNS la IP de un nombre.
route printTabla de rutas. En el router también show ip route.
curl <dirección>Descarga una página web y muestra el HTML.
cls · hostname · ayudaLimpiar pantalla, nombre del equipo, lista de comandos.

Guardar y compartir

La red se guarda sola en este navegador. Descargar crea un archivo .json que se puede abrir después. Compartir enlace copia una dirección que contiene la red completa, incluido el enunciado de la misión: útil para repartir ejercicios al alumnado.
